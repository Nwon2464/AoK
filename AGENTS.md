# AoK Project Instructions

## Working Style

- Before editing, inspect the actual code carefully.
- Do not rewrite large parts at once.
- Keep changes small and safe.
- Explain the action plan before modifying code.
- Do not change existing behavior unless explicitly requested.

## Project Direction

- Backend should use route/controller/service/client/mapper style.
- Frontend should gradually separate API calls from Redux actions.
- Prefer readability over clever code.
